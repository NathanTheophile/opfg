# OPFG fonts

The UI typography expects these local assets:

- `Cinzel-Bold.woff2` — weight 700
- `Inter-Regular.woff2` — weight 400
- `Inter-SemiBold.woff2` — weight 600

Equivalent `.ttf` files with the same basenames are also accepted by
`src/styles/typography.css`.

Typography roles:

- titles / hooks → Cinzel Bold
- body / information → Inter Regular
- controls / emphasized information → Inter SemiBold
