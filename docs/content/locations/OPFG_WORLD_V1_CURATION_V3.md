# OPFG — World V1 Curation Proposal V3

> **V3 change:** each Blue increases from 15 to **20 runtime Locations**, while keeping exactly **8 Birth Locations per Blue**.

## Final projected scale

- East Blue: **20**
- West Blue: **20**
- North Blue: **20**
- South Blue: **20**
- Blues total: **80**
- Outside Blues (Paradise V2 + New World + special regions): **108**
- **World V1 total: 188 runtime Locations**

Birth policy is unchanged: **32 Birth Locations total = 8 per Blue**, and no Paradise/New World/Special Location can be selected in Origins.

## Design impact

The four Blues are now large enough to support Childhood plus substantial early Active content without feeling like tutorial zones. East remains the most canon-dense Blue, while West/North/South gain more political, institutional, industrial and travel contexts.

The expansion does **not** change:

- Origins structure;
- the 8 Birth Locations per Blue;
- ship market rules;
- location service/tag vocabulary;
- Paradise V2 route topology;
- New World navigation policy;
- Egghead reference-only policy.

## Scope

V3 intentionally accepts the larger content scope. The final curated World V1 target is now **188 runtime Locations**. This is a content-volume increase, not a new gameplay-system requirement.
