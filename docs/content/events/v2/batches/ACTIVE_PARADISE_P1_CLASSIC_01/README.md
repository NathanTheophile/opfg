# ACTIVE_PARADISE_P1_CLASSIC_01

Generated integration package for the Wave 3 P1_CLASSIC Paradise worker.

1. Run `node verify-package.mjs` inside this package.
2. From the OPFG repo root, run `node <package>/apply-active-paradise-p1-classic-01.mjs`.
3. Then run `npm run validate-content`, `npm test`, `npm run build`.

The apply script refuses localization/file collisions and does not commit, push, open a PR, or modify engine/schema/save/UI/navigation code.
